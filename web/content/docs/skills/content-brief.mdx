The Content Brief Agent Skill tells a writer what a page needs to cover, and how to build it, to compete for one query.

Your agent checks demand for the keyword, reads the pages that rank now, and works out what searchers want and where those pages fall short. It then writes an outline that fits what your business actually offers, with meta tags, the trust signals the topic needs, and real internal links from your site.

It works for a new page or for an existing page you want to improve. For an existing page, it says which sections to keep, strengthen, or add instead of proposing a rewrite.

## What this skill helps your agent do

- Confirm the keyword has real demand and that no other page on your site already targets it.
- Read the live search results and name the page type and format they reward.
- Compare the pages that rank and find topic, depth, and quality gaps.
- Write an H1, URL slug, and H2/H3 outline with notes for each section.
- Draft a title tag and meta description.
- Name the information gain: what your page will offer that the current results do not.
- Suggest internal links from pages that already exist on your site.

## When to use it

Use this skill before writing or rewriting a page that should rank for a specific query. It fits blog posts, guides, service pages, category pages, and landing pages.

If you have a long keyword list, run [Keyword Clustering](/docs/skills/keyword-clustering) first and brief one cluster at a time.

## What you get back

A report with the brief in one line, the search intent, the pages ranking now and their gaps, the outline, meta tags, the information-gain angle, trust signals, and internal links. Ask for "just an outline" to get the short version.

## How to get the best result

- Give one keyword or one page URL per brief.
- Tell the agent what the page should make the reader do: buy, book, sign up, or learn.
- Connect Search Console so the agent sees the real queries an existing page gets.
- Share any first-hand data or experience you can put on the page; it is usually the angle that wins.

## Use it with OpenSEO MCP

Set up [OpenSEO MCP](/docs/mcp) so your agent can check keyword metrics, live search results, your crawled pages, and Search Console queries.
